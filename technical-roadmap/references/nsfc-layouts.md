# 国自然申请技术路线：布局参考

以下是从公开机构资料中实际看图提炼的编排方法，不是基金委统一绘图标准，也不代表获资助申请书。以用户材料、学科逻辑和申请要求为准；只借鉴结构，不复制原图、研究文本或水印。

## 先确定科学逻辑

可用“科学问题 → 假设 → 研究任务与证据 → 验证 → 科学认识”检查内容。假设须来自用户材料；探索性研究不必强加假设。每个任务对应研究对象、关键动作和预期证据，最终输出说明要回答什么问题，避免只写论文、专利等成果形式。保留对照、验证条件和实际依赖，不把相关性改写为因果。

## 三种结构

1. **证据递进**：观察或关联 → 关键机制检验 → 更高层级验证 → 科学认识。用顶部阶段条组织各层，层内可拆并行子节点。阶段顺序由研究决定，不固定为临床、动物、细胞的排列。
2. **多分支汇合再验证**：共同问题或多个输入 → 并行研究任务 → 证据汇总／模型或解释 → 独立验证 → 认识与适用范围。分支各自保留对象和参数，汇合表示证据整合，不能暗示参数可以混用。拟合与验证须区分；材料未安排独立验证时，不凭空补节点。
3. **双链互补，可选反馈**：实验与理论、测量与模型、临床证据与机制研究等两条主链，各自推进并在必要位置交换证据，最终共同回答科学问题。反馈仅在原方案支持时使用，并标明更新的对象，如参数、模型或试验条件；不能为装饰添加循环箭头。

大模块套小模块、短阶段条、整齐对齐可用于以上结构。不要为排版强行把真实交叉依赖改成单一流水线。

## 配色表达含义

填色按证据层级或模块职责分配，同类保持一致，必要时加简短图例。本skill交付图的内容框、阶段框、模块分组框及主箭头、反馈线均为黑色（`#000000`）；颜色仅用于标题与节点填充、模块浅底，原有虚实线形式可保留。参考原图的多色边界属于其历史样式，不沿用到交付图。不能只靠颜色区分逻辑，仍需标签、分组和箭头。配色变化不应造成字号不统一、框线过细或文字难读。
