# 国自然技术路线的研究逻辑规划

用于把研究方案转成图，或选择面上等申请图式。以用户材料和具体项目类别为准；这些结构不是基金委统一绘图标准，也不保证获资助。

## 建立对应关系

以简短内部表核对以下要素；不必把全部要素都画成独立框。

| 要素 | 需要回答的问题 |
| --- | --- |
| 科学问题 | 哪个现象、关系或机制尚待解释？ |
| 假设（可选） | 材料明确提出了什么待检验解释？探索性研究不强加假设。 |
| 研究任务 | 哪些任务分别回答问题的哪些部分？ |
| 对象与条件 | 各任务使用哪些样本、参数、干预和对照？ |
| 方法与证据 | 方法具体产生什么数据或观察，证据用于识别、比较还是验证？ |
| 预期认识 | 拟说明什么机制、规律或适用范围？保留“探讨、检验、阐明”等目标语气。 |

方法清单不能代替研究任务；论文、专利等成果形式不能代替要回答的科学问题。节点和箭头须能回溯到原文，不为使方案显得完整而新增实验。

## 从对应关系决定箭头

- 共用输入只有确实适用于所有支线时才汇入公共母线；专属对象、参数和干预单独连接对应任务。
- 并行任务分别生成证据后可汇合；章节、段落或研究层次的先后不自动构成实验依赖。
- 明确数据的用途：训练/拟合、参数标定、实验校正与验证不能互称。新样本或不同条件也不自动等于独立验证，须核对是否参与了拟合或方案选择。
- 反馈只在方案明确支持时画，并标明校正的是参数、模型还是试验条件。加号只表示互补，不能替代方向关系。
- 多层次证据互补不等于已证明因果。候选通路、预期模型与拟得到的认识不能画成确定结论。

## 可选结构

| 结构 | 适用情形与约束 |
| --- | --- |
| 目标递进 | 后段确需前段证据：短目标条组织阶段，段内仍可并行；不把所有方法强接成一条链。 |
| 多分支汇合 | 多项任务共同回答问题：各分支保留自己的输入、方法和证据，末端整合；原方案安排验证时再加入验证。 |
| 任务与指标矩阵 | 多对象或层次平行：按列组织任务，按行对齐准备、干预/检测及指标；行标签只是排版说明，不参与流程。 |
| 双链互补 | 实验与理论、临床与机制等各自推进，在有依据的位置交换证据；没有反馈依据时不加循环。 |

默认自上而下，以阶段条、大模块和短节点保持紧凑；真实交叉依赖优先于整齐排版。年度时间轴适合说明进度，不能取代科学逻辑。

## 配色与既有图修改

同类任务或证据层次使用同一填色色系，公共输入可用中性色填充，汇总目标可用强调色填充。少量浅模块底与较深标题底即可形成层次；内容框、阶段框、模块分组框及主箭头、反馈线均为黑色（`#000000`），原有虚实线形式可保留。标签与框线应使黑白打印仍可辨认；具体组合见 [multicolor.md](multicolor.md)。

用户仅要求改色时锁定已确认图，不改研究文字、字体、字号、坐标、框体、连线与线型。背景在连线和文字下方，改色后重新检查对比度和遮挡。

## 来源界限

布局参考与研究内容分别核对。只有实际看过图面才评价其分组、箭头或配色；公众号/知乎作者的推荐数量不是硬性规范，模板与培训图不是已资助证据。

需要查阅实际图样的公开来源和采用范围时，按需读 [国自然布局参考](nsfc-layouts.md) 或 [面上基金图式](mianshang-layouts.md)；不需要重新检索已有可用参考图。

真实案例同时核对可读方案及同题资助记录，记录题名、负责人、依托单位、年份、批准号和内容位置；受理号不能代替批准号。正文预览或框架片段按实际范围称呼，不能写成完整标书。已有案例的证据与边界见 [funded-cases.md](funded-cases.md)。

不复制第三方原图、长段研究文本或个人资料。已资助也不表示其研究假设已被证实；参考案例不能成为新用户研究事实。
